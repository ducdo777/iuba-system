# 🔧 Fix 404 Error - Vercel Deployment

## ✅ Đã Sửa

Đã sửa `vercel.json` để fix lỗi 404 NOT_FOUND:

### Thay Đổi

**Trước (sai):**
```json
{
  "version": 2,
  "builds": [...],
  "routes": [...]
}
```

**Sau (đúng):**
```json
{
  "version": 2,
  "buildCommand": "npm run build",
  "outputDirectory": "frontend/dist",
  "rewrites": [
    {
      "source": "/api/(.*)",
      "destination": "/api/index.ts"
    },
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ],
  "functions": {
    "api/index.ts": {
      "runtime": "@vercel/node"
    }
  }
}
```

### Giải Thích

1. **API Routes**: `/api/*` được route đến `/api/index.ts` (serverless function)
2. **Frontend Routes**: Tất cả routes khác (`/*`) được rewrite về `/index.html` để support React Router
3. **Build Output**: `frontend/dist` chứa built React app

## 🔍 Troubleshooting

### Vẫn Báo 404

1. **Kiểm tra build output:**
   - Đảm bảo `frontend/dist/index.html` tồn tại
   - Đảm bảo build thành công

2. **Kiểm tra routing:**
   - Verify `vercel.json` có rewrite `/*` → `/index.html`

3. **Kiểm tra deployment logs:**
   - Vercel Dashboard → Deployments → Click deployment → Logs

### API Routes Không Hoạt Động

1. **Kiểm tra function:**
   - Đảm bảo `api/index.ts` tồn tại
   - Verify `vercel.json` có route `/api/*` → `/api/index.ts`

2. **Kiểm tra environment variables:**
   - POSTGRES_URL, JWT_SECRET, NODE_ENV đã được set

### Frontend Load Nhưng Blank

1. **Kiểm tra console errors:**
   - Open browser DevTools → Console
   - Kiểm tra JavaScript errors

2. **Kiểm tra network requests:**
   - DevTools → Network
   - Verify API calls có được gửi đúng không
